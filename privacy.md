# Privacy Policy - Job Apply App

Last updated: 14 October 2026

Job Apply App is a personal tool that runs on its owner's own computer. It has one user: its owner, Naeem Sheikh.

**Data accessed.** With the owner's permission, the app reads job alert emails in the owner's Gmail account and sends a daily digest email to the owner's own address. It requests only the Gmail read-only and send permissions.

**Storage.** Job details are stored only in a local database on the owner's computer. The app runs no server and stores nothing elsewhere.

**Sharing.** Gmail data is never sold or shared for advertising. Job details taken from alert emails (title, company, location, description) are sent to the Anthropic Claude API only to score how well each job fits the owner.

**Google API Services.** The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
